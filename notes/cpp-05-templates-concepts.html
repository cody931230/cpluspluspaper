學習目標

  • 能夠撰寫函式模板與類別模板，並理解模板參數推導
  • 能夠理解模板實例化發生於編譯期，且定義通常需放在標頭檔中
  • 能夠使用 C++20 concepts 限制模板參數，改善錯誤訊息

核心概念

函式模板

函式模板以 template <typename T> 宣告，編譯器會依據呼叫時的參數型別推導 T，並為每組型別產生一份實例。模板本身不是函式，只有實例化後才會產生可執行的程式碼。

類別模板

類別模板如 std::vector<T>，使用時必須明確指定模板參數（C++17 起，部分情況可由建構子推導）。成員函式只在被使用時才會實例化。

Concepts（C++20）

Concept 是對模板參數的具名約束。例如 std::integral 要求型別為整數型別。使用 concept 可以讓錯誤在呼叫處就被指出，而不是在模板內部深層產生冗長的錯誤訊息。

定義位置

由於實例化需要看到完整的模板定義，模板通常整個寫在標頭檔中。若定義在 .cpp 中，其他翻譯單元將無法實例化它，導致連結錯誤。

程式範例

編譯指令：g++ -std=c++20 -Wall -Wextra main.cpp

範例 1：函式模板與 concept 約束

#include <concepts>
#include <iostream>

template <typename T>
T max_of(T a, T b) { return (a < b) ? b : a; }

template <std::integral T>
T gcd_of(T a, T b) {
    while (b != 0) {
        T t = b;
        b = a % b;
        a = t;
    }
    return a;
}

int main() {
    std::cout << max_of(3, 8) << '\n';           // T = int
    std::cout << max_of(2.5, 1.5) << '\n';       // T = double
    std::cout << gcd_of(48, 18) << '\n';         // 6
    // gcd_of(1.0, 2.0);  // 編譯錯誤：double 不滿足 std::integral
    return 0;
}

預期輸出：

8
2.5
6

範例 2：類別模板

#include <iostream>
#include <vector>

template <typename T>
class Stack {
public:
    void push(const T& v) { items_.push_back(v); }
    void pop()            { items_.pop_back(); }
    const T& top() const  { return items_.back(); }
    bool empty() const    { return items_.empty(); }
private:
    std::vector<T> items_;
};

int main() {
    Stack<std::string> s;
    s.push("first");
    s.push("second");
    std::cout << s.top() << '\n';   // second
    return 0;
}

預期輸出：

second

注意：範例 2 使用了 std::string，實際程式中應加上 #include <string>。

常見錯誤

  • 模板定義放在 .cpp 中：其他檔案包含標頭檔後無法實例化，出現連結錯誤。應將模板完整放在 .hpp 中。
  • 錯誤訊息過長：未使用 concept 時，錯誤通常出現在標準庫內部，訊息可能數百行。使用 concept 可以把錯誤指向呼叫處。
  • 假設模板參數可以隱式轉換：max_of(1, 2.0) 會因 T 推導衝突而無法編譯，需明確指定 max_of<double>(1, 2.0)。

課堂練習

練習 1：撰寫 concept Addable，要求型別 T 支援 + 運算，並以它約束 sum_of 函式 
#include <concepts>

template <typename T>
concept Addable = requires(T a, T b) {
    { a + b } -> std::convertible_to<T>;
};

template <Addable T>
T sum_of(T a, T b) { return a + b; }
練習 2：解釋為何 gcd_of(1.0, 2.0) 會在呼叫處被拒絕

因為 double 不滿足 std::integral，編譯器在模板參數約束檢查階段即報錯，不會進入函式本體。
