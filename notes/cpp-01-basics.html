學習目標

  • 能夠宣告基本型別並說明其大小與範圍會依平台而異
  • 能夠使用 const 與 auto 表達不可變性與型別推導
  • 能夠使用 std::cout 與 std::cin 進行基本輸入輸出
  • 能夠辨認整數除法與有號溢位等常見陷阱

核心概念

基本型別

常用的內建型別包括 bool、char、int、long long、double。C++ 標準只規定各型別的最小範圍，例如 int 至少能表示 16 位元有號整數；實際大小請用 sizeof 查詢，多數 32 位元平台上 int 為 4 位元組。

變數、const 與 auto

const 宣告的物件初始化後不可修改；constexpr（C++11）則要求值在編譯期即可求得。auto（C++11）由初始化式推導型別，適合型別名稱很長或由函式回傳的情況，但不應濫用到讓讀者無法判斷型別。

輸入輸出

std::cout 用於輸出，std::cin 用於輸入，兩者都定義於 <iostream>。使用 '\n' 換行通常比 std::endl 更好，因為 std::endl 會額外清空緩衝區。

整數除法

兩個整數相除時結果為整數，小數部分會被捨去。若要得到浮點數結果，需先將其中一個運算元轉為浮點數。

程式範例

編譯指令：g++ -std=c++17 -Wall -Wextra main.cpp

範例 1：宣告與輸出

#include <iostream>
#include <string>

int main() {
    int count = 3;                    // 有號整數
    double price = 99.5;              // 浮點數
    bool ok = count > 0;              // 比較結果為 bool
    const int max_size = 10;          // 初始化後不可修改
    auto name = std::string{"C++"};   // auto 推導為 std::string

    std::cout << name << " price: " << price << '\n';
    std::cout << "ok = " << std::boolalpha << ok << '\n';
    std::cout << "max_size = " << max_size << '\n';
    return 0;
}

預期輸出：

C++ price: 99.5
ok = true
max_size = 10

範例 2：整數除法與型別轉換

#include <iostream>

int main() {
    int a = 7, b = 2;
    std::cout << a / b << '\n';                        // 整數除法
    std::cout << a / static_cast<double>(b) << '\n';   // 浮點數除法
    return 0;
}

預期輸出：

3
3.5

常見錯誤

  • 有號整數溢位是未定義行為（UB）：int 超過最大值時結果不確定，編譯器可能做出與直覺不同的最佳化。無號整數的溢位則有明確定義（數值取模）。
  • 有號與無號比較：int i = -1; unsigned u = 1; 時，i < u 的結果為 false，因為 i 會被轉為無號數。開啟 -Wall -Wextra 可取得警告。
  • 標頭檔中使用 using namespace std;：會汙染所有包含此檔案的程式碼，應只在 .cpp 的局部範圍使用，或直接寫 std::。

課堂練習

練習 1：讀入三個整數並輸出平均值（保留小數） 
#include <iostream>

int main() {
    int x, y, z;
    std::cin >> x >> y >> z;
    double avg = (x + y + z) / 3.0;   // 3.0 為 double，避免整數除法
    std::cout << avg << '\n';
    return 0;
}
練習 2：判斷西元年份是否為閏年

規則：能被 4 整除且不能被 100 整除，或能被 400 整除。

bool is_leap(int year) {
    return (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
}
