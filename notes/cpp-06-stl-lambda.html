學習目標

  • 能夠依需求選擇適當的容器（vector、map、unordered_map）
  • 能夠使用演算法搭配 lambda 取代手寫迴圈
  • 能夠辨認迭代器失效等常見錯誤

核心概念

容器與迭代器

STL 將資料結構（容器）與演算法透過迭代器（iterator）分離。std::vector 為連續記憶體，隨機存取快，預設應優先考慮。std::map 以有序樹狀結構儲存（標準未規定實作，但要求對數時間複雜度），std::unordered_map 以雜湊表實作，平均查詢為常數時間。

演算法

如 std::sort、std::find_if、std::count_if 等演算法接受迭代器區間與可呼叫物件，不需要知道容器的具體型別。

Lambda（C++11）

Lambda 運算式 [捕獲](參數){ 本體 } 會產生一個匿名函式物件。捕獲列表決定外部變數如何被使用：[x] 為複製，[&x] 為參考。

Ranges（C++20）

std::ranges 讓演算法可以直接接受容器本身，並提供 views（如 views::filter）以惰性方式組合管線，不會產生中間容器。

程式範例

編譯指令：g++ -std=c++20 -Wall -Wextra main.cpp

範例 1：演算法搭配 lambda

#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v{5, 2, 8, 1, 9};
    std::sort(v.begin(), v.end());

    int threshold = 4;
    auto n = std::count_if(v.begin(), v.end(),
        [threshold](int x) { return x > threshold; });   // 以複製方式捕獲
    std::cout << "count > 4: " << n << '\n';
    return 0;
}

預期輸出：

count > 4: 3

範例 2：C++20 ranges 管線

#include <iostream>
#include <ranges>
#include <vector>

int main() {
    std::vector<int> v{1, 2, 5, 8, 9};
    auto evens = v | std::views::filter([](int x) { return x % 2 == 0; });
    for (int x : evens) std::cout << x << ' ';
    std::cout << '\n';
    return 0;
}

預期輸出：

2 8

常見錯誤

  • 在迴圈中對 vector 使用 push_back 導致迭代器失效：容量不足時會重新配置記憶體，原有迭代器全部失效。需要時應先呼叫 reserve，或重新取得迭代器。
  • 迭代中直接 erase：erase 之後原迭代器失效。應使用 it = v.erase(it);，或使用 std::erase_if（C++20）。
  • 回傳以參考捕獲區域變數的 lambda：函式結束後被捕獲的變數已被銷毀，呼叫 lambda 為未定義行為。需要離開作用域時應使用複製捕獲。

課堂練習

練習 1：給定 std::vector<std::string>，計算長度超過 5 的字串數量 
auto n = std::count_if(words.begin(), words.end(),
    [](const std::string& s) { return s.size() > 5; });
練習 2：比較 std::map 與 std::unordered_map 的適用情境

若需要依鍵排序的遍歷，或需要 lower_bound 等有序操作，選擇 map；若只需快速查找且不在意順序，選擇 unordered_map。
