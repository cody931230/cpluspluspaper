學習目標

  • 能夠區分傳值、傳參考與傳 const 參考的差異與適用時機
  • 能夠設計具有預設參數與多載的函式
  • 能夠避免回傳區域變數參考等懸空參考問題

核心概念

傳值、傳參考與 const 參考

預設情況下 C++ 採用傳值（pass by value），函式內部操作的是複製品。T& 表示參考，函式內對參數的修改會影響原物件。當參數只需讀取但型別較大（如 std::string）時，使用 const T& 可以避免複製，且允許傳入臨時物件。

函式多載

同一作用域中，只要參數型別、數量或順序不同，就可以定義同名函式。回傳型別不同不能作為多載依據。

預設參數

預設參數只能寫在宣告中一次，且從右往左連續指定。

inline 的真正意義

在現代 C++ 中，inline 的主要語意是允許函式定義出現在多個翻譯單元中，而不是要求編譯器一定內嵌展開。是否內嵌由編譯器決定。

程式範例

編譯指令：g++ -std=c++17 -Wall -Wextra main.cpp

範例 1：三種參數傳遞方式

#include <iostream>
#include <string>

void by_value(int n)            { ++n; }        // 修改的是複製品
void by_ref(int& n)            { ++n; }        // 修改原物件
void show(const std::string& s) { std::cout << s << '\n'; }  // 唯讀、免複製

int main() {
    int x = 10;
    by_value(x);
    std::cout << x << '\n';   // 10
    by_ref(x);
    std::cout << x << '\n';   // 11
    show("temporary string");  // const 參考可接受臨時物件
    return 0;
}

預期輸出：

10
11
temporary string

範例 2：多載與預設參數

#include <iostream>

int add(int a, int b = 0)       { return a + b; }
double add(double a, double b)  { return a + b; }

int main() {
    std::cout << add(2, 3) << '\n';        // 呼叫 int 版本：5
    std::cout << add(2.5, 0.5) << '\n';    // 呼叫 double 版本：3
    std::cout << add(7) << '\n';           // 使用預設參數：7
    return 0;
}

預期輸出：

5
3
7

常見錯誤

  • 回傳區域變數的參考：函式結束時區域變數已被銷毀，回傳的參考成為懸空參考（dangling reference），存取它是未定義行為。正確做法是回傳值，或回傳由呼叫者提供的物件參考。
  • 對 std::string 參數使用傳值：每次呼叫都會複製字串，應改用 const std::string&。
  • 在標頭檔的兩個地方重複指定預設參數：宣告與定義都寫預設值會造成編譯錯誤，預設值只寫在宣告處。

課堂練習

練習 1：實作 swap，使兩個 int 的值互換

必須使用參考參數，否則函式內的交換不會影響呼叫端。

void swap_int(int& a, int& b) {
    int tmp = a;
    a = b;
    b = tmp;
}
練習 2：找出下列程式的錯誤 
int& make_value() {
    int v = 42;
    return v;   // 錯誤：回傳區域變數的參考
}

修正：改為 int make_value()，回傳值本身。
