學習目標

  • 能夠撰寫具有建構子、解構子與封裝介面的類別
  • 能夠解釋 RAII 原則，並用它管理資源
  • 能夠依據 Rule of Zero／Three／Five 決定特殊成員函式的設計

核心概念

類別與封裝

class 預設成員為 private，struct 預設為 public。資料成員應設為 private，只透過成員函式存取，以維持不變式（invariant）。

建構子與初始化列表

成員應在初始化列表中初始化，而非在建構子主體中賦值。單一參數的建構子建議加上 explicit，以避免隱含轉換。

RAII

RAII（Resource Acquisition Is Initialization）是指：資源在物件建構時取得，在解構時釋放。由於區域物件在離開作用域時必定會解構（包括例外發生時），RAII 能讓資源管理不依賴人工記得呼叫釋放函式。標準庫中的 std::lock_guard、std::fstream 都是 RAII 的例子。

Rule of Zero／Three／Five

若類別直接持有資源（如原始指標），通常需要處理解構、拷貝建構、拷貝指派，C++11 後還需考慮移動建構與移動指派（Rule of Five）。更好的做法是讓成員本身就是 RAII 類型（如 std::vector、智慧指標），使類別不需要自訂任何特殊成員函式（Rule of Zero）。

程式範例

編譯指令：g++ -std=c++17 -Wall -Wextra main.cpp

範例 1：以 RAII 管理動態陣列，並禁止拷貝

#include <cstddef>
#include <iostream>

class IntBuffer {
public:
    explicit IntBuffer(std::size_t n) : size_(n), data_(new int[n]{}) {}
    ~IntBuffer() { delete[] data_; }

    IntBuffer(const IntBuffer&) = delete;             // 禁止拷貝，避免 double delete
    IntBuffer& operator=(const IntBuffer&) = delete;

    int& at(std::size_t i)       { return data_[i]; }
    std::size_t size() const      { return size_; }

private:
    std::size_t size_;
    int* data_;
};

int main() {
    IntBuffer buf(4);
    buf.at(2) = 99;
    std::cout << buf.at(2) << " size=" << buf.size() << '\n';
    // IntBuffer copy = buf;   // 編譯錯誤：拷貝建構子已被刪除
    return 0;
}  // 離開作用域時自動呼叫 ~IntBuffer()，釋放記憶體

預期輸出：

99 size=4

範例 2：同樣功能，以 Rule of Zero 實作

#include <cstddef>
#include <vector>

class IntBuffer {
public:
    explicit IntBuffer(std::size_t n) : data_(n) {}   // vector 負責所有資源管理
    int& at(std::size_t i)       { return data_[i]; }
    std::size_t size() const      { return data_.size(); }
private:
    std::vector<int> data_;
};

此版本不需要任何解構子、拷貝或移動函式，且可以安全地被拷貝與移動。

常見錯誤

  • 淺拷貝導致 double delete：編譯器產生的預設拷貝建構子只會複製指標值，兩個物件會釋放同一塊記憶體。若類別持有原始資源，應刪除拷貝或實作深拷貝。
  • 忘記 delete[]：以 new[] 配置的陣列必須以 delete[] 釋放，混用 delete 是未定義行為。
  • 在建構子主體中賦值而非初始化：成員會先被預設建構再被賦值，對於 const 成員或參考成員則根本無法編譯。

課堂練習

練習 1：為 IntBuffer 加入移動建構子，使其可以被移動但不能被拷貝 
IntBuffer(IntBuffer&& other) noexcept
    : size_(other.size_), data_(other.data_) {
    other.size_ = 0;
    other.data_ = nullptr;   // 讓來源物件的解構子不會再次釋放
}
練習 2：說明為何 std::vector 版本能滿足 Rule of Zero

std::vector 本身已經是 RAII 類型，並正確定義了解構、拷貝與移動。包含它的類別只需依賴其預設行為即可。
