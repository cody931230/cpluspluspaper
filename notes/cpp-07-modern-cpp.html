核心概念

右值參考與移動語意

右值參考 T&&（C++11）可以綁定到即將被銷毀的臨時物件。移動建構子利用這一點，把來源物件持有的資源「接收」過來，而不是複製。移動後的來源物件仍處於有效但未指定的狀態，只能安全地解構或重新賦值。

std::move

std::move 本身不移動任何東西，它只是把運算元轉為右值參考，允許後續的移動建構或移動指派被選用。

noexcept 的重要性

std::vector 在重新配置時，只有在元素的移動建構子不會拋出例外時才會使用移動；否則會退回複製，以保證強例外安全。因此移動操作通常應標記為 noexcept。

std::optional、std::variant 與結構化綁定（C++17）

std::optional<T> 表示「可能有值，也可能沒有」，取代以特殊值或指標表示缺值的寫法。std::variant 是型別安全的聯合體，在任一時刻只持有其中一種型別。結構化綁定 auto [a, b] = ... 可以同時解開 pair、tuple 或結構的成員。

程式範例

編譯指令：g++ -std=c++17 -Wall -Wextra main.cpp

範例 1：移動建構子與 std::move

#include <iostream>
#include <string>
#include <utility>

class Message {
public:
    explicit Message(std::string text) : text_(std::move(text)) {}

    Message(Message&& other) noexcept : text_(std::move(other.text_)) {}
    Message& operator=(Message&& other) noexcept {
        text_ = std::move(other.text_);
        return *this;
    }

    const std::string& text() const { return text_; }

private:
    std::string text_;
};

int main() {
    Message a{"hello, move semantics"};
    Message b = std::move(a);    // 呼叫移動建構子
    std::cout << b.text() << '\n';
    // a.text() 仍可呼叫，但內容為未指定狀態，不應再依賴其值
    return 0;
}

預期輸出：

hello, move semantics

範例 2：std::optional 與結構化綁定

#include <iostream>
#include <map>
#include <optional>
#include <string>

std::optional<int> find_age(const std::map<std::string, int>& db,
                              const std::string& name) {
    auto it = db.find(name);
    if (it == db.end()) return std::nullopt;   // 表示沒有值
    return it->second;
}

int main() {
    std::map<std::string, int> db{{"Ann", 20}, {"Ben", 22}};

    if (auto age = find_age(db, "Ann"); age) {   // if 初始化陳述式（C++17）
        std::cout << "Ann: " << *age << '\n';
    }

    for (const auto& [name, age] : db) {       // 結構化綁定
        std::cout << name << " -> " << age << '\n';
    }
    return 0;
}

預期輸出：

Ann: 20
Ann -> 20
Ben -> 22

常見錯誤

  • 移動建構子未標 noexcept：std::vector 擴容時會退回複製，效能下降且容易被忽略。
  • 使用已被移走的物件：std::move 之後的物件只能安全地賦值或解構，讀取其內容的行為不被保證。
  • 以為 std::move 會讓原物件變成 nullptr：這只對某些型別（如 unique_ptr）在其移動操作中成立，取決於型別自身的移動實作。
  • 對 const 物件使用 std::move：const T&& 無法綁定到移動建構子，會退回複製，不會產生預期效果。

課堂練習

練習 1：以 std::optional<double> 實作安全除法，除數為 0 時回傳空值 
std::optional<double> safe_div(double a, double b) {
    if (b == 0.0) return std::nullopt;
    return a / b;
}
練習 2：預測下列程式是否會複製字串，並說明原因 
std::vector<std::string> v;
std::string s = "data";
v.push_back(std::move(s));   // 移動，不複製

std::move(s) 將 s 轉為右值，push_back 會選擇移動建構，因此不會複製字串內容。
